# Documentation Rules

- Keep claims aligned with repository evidence
- Separate implemented behavior from planned behavior
- Record alternatives and tradeoffs
- Prefer concise, concrete explanations
- Use exact commands verified from package scripts
- Never claim tests passed without execution
- Keep `.ai/NEXT.md` concise
- Keep memory current rather than append-only
- Do not store chain-of-thought
