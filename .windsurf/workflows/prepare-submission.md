# /prepare-submission

Perform the final interview submission review.

## Steps

1. Verify Levels 1–3 and required concurrency behavior
2. Review all README setup commands
3. Run the complete quality-gate workflow
4. Review security controls
5. Review architecture and domain documentation
6. Verify AI disclosure
7. Review Git status for accidental or sensitive files
8. Check environment examples for secrets
9. Review commit history for understandable progression
10. Check that production evolution is clearly distinguished from implemented behavior
11. Review `docs/INTERVIEW_GUIDE.md`
12. Produce a concise submission-readiness report
13. Do not declare readiness while required checks fail
